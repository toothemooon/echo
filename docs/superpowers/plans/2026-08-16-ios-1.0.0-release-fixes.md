# iOS 1.0.0 Release Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Correct the four confirmed Japanese attribution conflicts and release metadata, make Clear All deterministic against unfinished asynchronous writes, and let startup fall back to the system quote font when the bundled font fails.

**Architecture:** Keep the existing module layout. A dependency-free process-wide promise tail serializes every active `@echo/` mutation, including Clear All; a pure startup helper converts Expo's font hook state into readiness and an effective runtime quote font. Catalog changes are narrow JSON record corrections with tests guarding normalized uniqueness, attribution, contexts, and counts.

**Tech Stack:** TypeScript 6, React Native 0.86, Expo 57, AsyncStorage 2.2, Expo Font, Node.js `node:test`, JSON catalog assets.

## Global Constraints

- Historical Echo remains visible in iOS 1.0.0.
- Keep `ja-wikiquote-3624-05` and `ja-wikiquote-1888-07`; delete `ja-wikiquote-1818-09` and `ja-wikiquote-1430-11`.
- Final counts are English 1,282, Simplified Chinese 823, Japanese 1,820, total 3,925, and 952 language-scoped authors.
- Use one minimal global storage write queue; do not add cancellation, epochs, transactions, retries, or a storage framework.
- The Clear All regression test must overlap an unfinished asynchronous write with the clear operation.
- A font error makes startup ready and selects the system quote font for the current runtime without overwriting the persisted preference.
- Do not add artifact manifests, checksums, Git LFS, release-data infrastructure, or JSON freezing work.
- Do not modify or restore `.playwright-mcp`.
- Do not change Android, Web, batch tooling, package-size, dependency-audit, or unrelated accessibility findings.

- [ ] **Step 1: Write the unfinished-write-versus-clear regression test**

Create `tests/storageClear.test.ts` with an in-memory storage class and a manually released write:

```ts
import test from "node:test";
import assert from "node:assert/strict";
import { clearLocalData } from "../src/storage/clearLocalData";
import {
  enqueueStorageMutation,
  waitForStorageMutations,
} from "../src/storage/storageMutationQueue";

class MemoryStorage {
  readonly values = new Map<string, string>();

  async getAllKeys(): Promise<string[]> {
    return [...this.values.keys()];
  }

  async multiRemove(keys: readonly string[]): Promise<void> {
    for (const key of keys) this.values.delete(key);
  }

  async setItem(key: string, value: string): Promise<void> {
    this.values.set(key, value);
  }
}

test("Clear All waits for an unfinished write and removes the key it creates", async () => {
  await waitForStorageMutations();
  const storage = new MemoryStorage();
  storage.values.set("@echo/theme", "dark");
  storage.values.set("third-party/key", "keep");

  let releaseWrite!: () => void;
  const writeGate = new Promise<void>((resolve) => {
    releaseWrite = resolve;
  });
  const pendingWrite = enqueueStorageMutation(async () => {
    await writeGate;
    await storage.setItem("@echo/saved_quotes", "[]");
  });

  let clearCompleted = false;
  const pendingClear = clearLocalData(storage).then(() => {
    clearCompleted = true;
  });
  await Promise.resolve();
  await Promise.resolve();
  assert.equal(clearCompleted, false);

  releaseWrite();
  await Promise.all([pendingWrite, pendingClear]);
  assert.deepEqual(
    [...storage.values.keys()].filter((key) => key.startsWith("@echo/")),
    [],
  );
  assert.equal(storage.values.get("third-party/key"), "keep");
});

test("a rejected storage mutation does not poison the global queue", async () => {
  await assert.rejects(
    enqueueStorageMutation(async () => {
      throw new Error("write failed");
    }),
    /write failed/,
  );

  let ran = false;
  await enqueueStorageMutation(async () => {
    ran = true;
  });
  assert.equal(ran, true);
});
```

The first test catches the original post-clear key resurrection. The second catches a promise tail left permanently rejected.

Create `src/storage/storageMutationQueue.ts`:

```ts
let mutationTail: Promise<void> = Promise.resolve();

export function enqueueStorageMutation<T>(
  operation: () => Promise<T>,
): Promise<T> {
  const result = mutationTail.then(operation);
  mutationTail = result.then(
    () => undefined,
    () => undefined,
  );
  return result;
}

export function waitForStorageMutations(): Promise<void> {
  return mutationTail;
}
```

Change `src/storage/clearLocalData.ts` so the key snapshot and `multiRemove` execute inside `enqueueStorageMutation`. Define the narrow injectable type:

```ts
export type EchoStorage = {
  getAllKeys(): Promise<readonly string[]>;
  multiRemove(keys: readonly string[]): Promise<void>;
};

export function clearLocalData(
  storage: EchoStorage = AsyncStorage,
): Promise<void> {
  return enqueueStorageMutation(async () => {
    const keys = await storage.getAllKeys();
    const echoKeys = keys.filter((key) => key.startsWith(ECHO_STORAGE_PREFIX));
    if (echoKeys.length > 0) await storage.multiRemove(echoKeys);
  });
}
```

import type { QuoteFont } from "../storage/preferences";

type FontError = Error | null | undefined;

export function isFontReady(
  fontsLoaded: boolean,
  fontError: FontError,
): boolean {
  return fontsLoaded || fontError != null;
}

export function resolveRuntimeQuoteFont(
  preference: QuoteFont,
  fontError: FontError,
): QuoteFont {
  return fontError == null ? preference : "system";
}
